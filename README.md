# موقع م. أنيس — النسخة 2 (متعدد اللغات + حسابات + لوحة تحكم ديناميكية)

موقع كامل: HTML/CSS/JS من جهة الواجهة، و **Supabase** (مجاني) من جهة قاعدة البيانات
والمصادقة والتخزين. لا حاجة لأي خادم تديره أنت بنفسك.

## هيكل الملفات

```
website/
├── index.html          ← الصفحة الرئيسية العامة
├── admin.html           ← لوحة تحكم المشرف (محمية)
├── css/style.css        ← كل التصميم
├── js/
│   ├── config.js         ← مفاتيحك (عدّل هذا فقط للربط الأولي)
│   ├── supabase-client.js
│   ├── i18n.js           ← نظام اللغات الثلاث
│   ├── auth.js           ← تسجيل الدخول / حساب جديد
│   ├── main.js           ← منطق الصفحة الرئيسية
│   └── admin.js          ← منطق لوحة التحكم
├── sql/schema.sql        ← نفّذه مرة واحدة في Supabase
└── README.md
```

## الإعداد (15 دقيقة، مرة واحدة فقط)

### 1) أنشئ مشروع Supabase مجاني
اذهب إلى [supabase.com](https://supabase.com) → New Project (اختر كلمة مرور قوية لقاعدة البيانات واحفظها).

### 2) نفّذ مخطط قاعدة البيانات
من لوحة Supabase: **SQL Editor → New query** → افتح ملف `sql/schema.sql` من هذا المشروع، انسخ محتواه كاملاً، الصقه، ثم اضغط **Run**.
هذا ينشئ كل الجداول، صلاحيات الأمان (RLS)، ومساحة تخزين الملفات تلقائيًا.

### 3) انسخ مفاتيح مشروعك
من **Project Settings → API**:
- انسخ **Project URL**
- انسخ **anon public key**

افتح `js/config.js` والصقهما مكان القيم النائبة:
```js
SUPABASE_URL: 'https://xxxxxxxx.supabase.co',
SUPABASE_ANON_KEY: 'eyJhbGciOi...',
```

### 4) أنشئ حسابك وفعّل صلاحية المشرف
1. افتح `index.html` في المتصفح (أو بعد النشر)، اضغط "تسجيل الدخول" → أنشئ حسابًا ببريدك.
2. تحقق من بريدك واضغط رابط التفعيل (Supabase يرسله تلقائيًا).
3. ارجع إلى **SQL Editor** في Supabase ونفّذ (استبدل البريد ببريدك الفعلي):
   ```sql
   update public.profiles set is_admin = true where email = 'you@example.com';
   ```
4. سجّل الدخول من جديد في الموقع → ستظهر لك "لوحة التحكم" في قائمة حسابك أعلى الموقع.

بهذا فقط أنت المشرف؛ أي زائر آخر ينشئ حسابًا يبقى مستخدمًا عاديًا (تصفح + مفضلة فقط)، ولا يمكنه رؤية أو استخدام `admin.html` — الحماية مطبّقة فعليًا على مستوى قاعدة البيانات (RLS) وليست مجرد إخفاء بالواجهة.

## كيف تضيف برنامجًا أو تطبيقًا جديدًا (من الآن فصاعدًا)

**لا حاجة لأي كود.** من `admin.html`:
1. اختر "رفع ملف" أو "رابط خارجي فقط"
2. اسحب الملف أو انقر لاختياره (أي نوع: APK, EXE, ZIP, MP4, PDF, TXT...)
3. املأ الاسم والوصف (بالعربي إجباري، الفرنسية/الإنجليزية اختياريان — إن تركتهما فارغين سيظهر النص العربي تلقائيًا لتلك اللغات)
4. اختر التصنيف، اضغط "رفع ونشر"
5. العنصر يظهر فورًا في الموقع العام — بدون أي نشر (Deploy) جديد

## اللغات الثلاث

- التبديل عبر الأزرار AR / FR / EN أعلى الموقع، يُحفظ اختيار الزائر تلقائيًا (localStorage).
- كل نصوص الواجهة (القوائم، الأزرار، العناوين) مترجمة بالكامل في `js/i18n.js`.
- لإضافة نص جديد: أضف مفتاحًا في القاموس الثلاثي داخل `TRANSLATIONS`، ثم استخدم `data-i18n="مفتاحك"` على أي عنصر HTML.
- محتوى البرامج (الاسم/الوصف) يُترجم لكل عنصر بشكل مستقل من لوحة التحكم نفسها.

## الحسابات وتصفح الزوار

- **بدون تسجيل دخول**: تصفح كامل لكل الموقع، التحميل، استخدام نموذج التواصل — كما في Vistaprint/Autodesk.
- **مع تسجيل الدخول**: إضافة عناصر للمفضلة (⭐ على كل كارت)، وأساس جاهز لتوسيع الميزات لاحقًا (سجل تنزيلات، إشعارات تحديثات...).
- لا يوجد أي حائط يمنع الزائر غير المسجل من رؤية أي قسم.

## النشر

نفس الخطوات السابقة (Vercel أو Netlify أو GitHub Pages) — الموقع لا يزال ملفات ثابتة بالكامل من ناحية الاستضافة؛ فقط تأكد أن `js/config.js` يحتوي مفاتيحك **قبل** رفع الملفات للاستضافة.

⚠️ ملاحظة أمان: `anon public key` مصمم ليكون علنيًا في كود الواجهة (هذا طبيعي في Supabase) — الحماية الفعلية من صلاحيات RLS في قاعدة البيانات، وليس بإخفاء هذا المفتاح.

## معرض الأعمال أصبح ديناميكيًا أيضًا

بالضبط كالبرمجيات: من `admin.html` → قسم "إضافة عمل جديد للمعرض" → ارفع صورة أو فيديو (JPG/PNG/WEBP/MP4)، أضف عنوانًا (عربي إجباري)، اختر تصنيفًا، وينشر فورًا في قسم `#portfolio` بالموقع. لا حاجة لتعديل أي كود لإضافة أعمال جديدة بعد الآن.

## ملفات SEO و PWA

- **`favicon.ico`** و**`assets/icons/`**: أيقونات الموقع، تم توليدها تلقائيًا من نفس شعار الدائرة النحاسية في الهيدر — استبدلها بشعارك الفعلي متى صممته.
- **`manifest.json`**: يسمح للزوار بتثبيت الموقع كتطبيق على الهاتف/الحاسوب (PWA). عدّل `name`/`short_name` إذا غيّرت اسم مشروعك.
- **`robots.txt`**: يمنع أرشفة `admin.html` في جوجل تلقائيًا. **مهم:** استبدل `YOUR-DOMAIN.com` بدومينك الفعلي بعد الشراء.
- **`sitemap.xml`**: نفس الأمر — استبدل `YOUR-DOMAIN.com` بدومينك، ثم أضف الرابط في Google Search Console بعد النشر.

## أشياء تبقى عليك (اختيارية)

- استبدل رقم الواتساب وروابط GitHub/LinkedIn في `js/config.js`
- استبدل `YOUR-DOMAIN.com` في `robots.txt` و`sitemap.xml` بدومينك الحقيقي
- فعّل "تأكيد البريد الإلكتروني" أو عطّله من Supabase → Authentication → Settings حسب رغبتك
- الخطة المجانية في Supabase: حد أقصى 50 ميغا للملف الواحد و1 غيغا تخزين إجمالي — كافٍ للبداية، وقابل للترقية لاحقًا إن كبر عدد برامجك وفيديوهاتك
